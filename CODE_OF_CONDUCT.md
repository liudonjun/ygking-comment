# 行为准则 / Code of Conduct

## 适用范围 / Scope

本准则适用于本仓库及其关联的 GitHub Discussions 中发布的所有内容和互动，包括讨论、评论、回复及其他用户内容。参与讨论即表示同意遵守本准则。

This Code of Conduct applies to all content and interactions in this repository and its associated GitHub Discussions, including discussions, comments, replies, and other user content. By participating, you agree to follow these rules.

## 基本要求 / Expected Conduct

请保持尊重、友善和就事论事。欢迎不同意见，但请围绕内容交流，不要攻击或贬损他人。

Be respectful, considerate, and focused on the topic. Disagreement is welcome; personal attacks and degrading remarks are not.

## 不允许的内容 / Unacceptable Content

以下行为和内容不被允许：

- 辱骂、侮辱、人身攻击、仇恨言论或歧视性内容；
- 广告、垃圾信息、未经请求的推广，或反复发布无关内容；
- 色情、露骨性内容、性骚扰或不受欢迎的性暗示；
- 骚扰、威胁、恐吓、跟踪，或未经同意公开他人的个人信息；
- 冒充他人、恶意链接，以及其他破坏讨论秩序或侵害他人权益的内容。

The following behavior and content are not allowed:

- Insults, abuse, personal attacks, hate speech, or discriminatory content;
- Advertising, spam, unsolicited promotion, or repeated off-topic posts;
- Pornographic or sexually explicit content, sexual harassment, or unwelcome sexual advances;
- Harassment, threats, intimidation, stalking, or sharing someone's personal information without consent;
- Impersonation, malicious links, or other content that disrupts discussion or violates others' rights.

## 管理措施 / Moderation

仓库维护者可根据违规内容的严重程度、影响和既往记录采取措施，包括删除评论或其他内容、警告、限制参与讨论，或禁止相关账号继续参与本仓库的讨论。严重违规或屡次违规时，维护者可不经事先警告直接删除内容并封禁账号。

Repository maintainers may act based on the severity and impact of a violation and the user's history. Measures may include removing comments or other content, issuing a warning, restricting participation, or banning an account from further discussion in this repository. For severe or repeated violations, maintainers may remove content and ban an account without a prior warning.

如需报告违规内容，请使用 GitHub 的举报功能，或联系本仓库维护者，并尽可能附上相关内容的链接。

To report a violation, use GitHub's reporting features or contact the repository maintainers, and include a link to the relevant content when possible.
